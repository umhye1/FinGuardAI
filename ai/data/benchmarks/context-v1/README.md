# Context benchmark v1 — synthetic development fixture

작성일: 2026-09-29. 84개 모두 저장소에서 직접 작성한 합성 문장이다.
공식 기관이 라벨링한 데이터나 실제 사용자 표본이 아니며, 성능은 실제 서비스로 일반화할 수 없다.

- PHISHING: 민감정보·선입금·위험 앱 설치 등을 실제로 유도하는 문맥.
- PREVENTION: 예방 안내, 위험 요청을 경고하는 인용. 인용부호 자체로 안전 판정하지 않는다.
- NORMAL: 위 두 의도가 없는 일상 대화·일반 안내. 발신자의 진위를 보증하는 라벨이 아니다.
- 예방 안내처럼 시작해 실제로 정보를 요구하는 문장은 PHISHING이다.

train 36 / dev 18 / test 30. 동일 시나리오의 세 가지 의도 대비 문장은 같은 group과 split에만 둔다.
대출·택배 같은 넓은 도메인 전체를 holdout한 실험은 아니다. 새로운 요청/사칭 시나리오를
holdout하고, 일부 적대적 예방 문구 사례도 포함했다. 동일 표현(본인인증 등)은 split 간 존재한다.
파일 해시·ID·공백/유니코드 정규화 텍스트·group 중복을 검증한다. 의미적 중복 완전 제거를
보장하지 않으므로 별도 검수자가 라벨과 템플릿 독립성을 검토해야 한다.

고정 test를 보고 특징·임계값을 변경하면 이 test는 개발셋이 된다. 후속 개선에는 새로운
잠금 test가 필요하다. dev에서만 정해진 임계값 후보를 선택한다. test 수가 작으므로
비율과 함께 분자/분모, 보류율을 보고한다. 독립 라벨 검수는 아직 수행하지 않았다.
